Data-driven navigatie via :items

Genest menu — <c-menu :items>

Eén array met children → het component bouwt de submenu's zelf (submenu's hier inline gemaakt voor de screenshot).

{% set NAV = [ {'label':'Overzicht','href':'/','icon':'home','active':True}, {'label':'Beheer','icon':'gear','children':[ {'label':'Gebruikers','href':'/beheer/users','icon':'person'}, {'label':'Rollen','href':'/beheer/roles','icon':'shield-check-mark','children':[ {'label':'Systeemrollen','href':'/beheer/roles/system'}, {'label':'Teamrollen','href':'/beheer/roles/team'} ]} ]}, {'label':'Rapporten','href':'/rapporten','icon':'chart-x-y-axis-line'} ] %}
