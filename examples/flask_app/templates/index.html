It just works This whole page is styled by one tag. <c-page> renders the full HTML document and pulls in the CSS (and JS, for web-component themes) for whatever design system you activated — you never link a stylesheet by hand.
1 Add the packages: lord-of-the-components and a design system such as lotc-rvo. 2 Call setup_components(env, design_systems=["rvo"]) and serve get_static_roots() under /static/lotc/. 3 Author templates with <c-*> tags. Switch design systems by changing one argument. The same markup renders under a different design system by changing design_systems=["rvo"] to another installed system — no template edits. Repository
