Lord of the Components (LOTC) provides a set of semantic HTML components that are processed through Jinja2 and rendered with RVO/Utrecht CSS styling. Browse all components with every variant — auto-generated from component definitions. Components are defined in TypeScript definitions and rendered via Jinja2 templates. LOTC components use a simple <c-*> tag syntax: Use <c-button type="primary" name="Click me"/> to render a styled button.
